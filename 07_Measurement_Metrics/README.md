# 07. Measurement Metrics — Đo lường và số liệu

## Framework đo lường UX

### HEART Framework (Google)
Google's framework để đo lường UX:
- **H**appiness — satisfaction, NPS, CSAT
- **E**ngagement — DAU, MAU, session length, frequency
- **A**doption — new user signups, feature adoption rate
- **R**etention — returning users, churn rate
- **T**ask Success — completion rate, time on task, error rate

Ref: https://developers.google.com/search/mobile-sites/good-ux-quantitative-research

### Google UX Scorecard (2025)
Mở rộng từ HEART, thêm:
- **Perceived System Quality**: App responsiveness, crash rate, loading time
- **Developer Experience**: API quality, documentation

### The THREE Cs
- **Conversion**: Tỷ lệ hoàn thành mục tiêu (signup, purchase, form submit)
- **Completion**: Task completion rate
- **C Sat**: Customer Satisfaction (CSAT, NPS, CES)

## Metrics cho User Research

### SUS — System Usability Scale (10 câu)
Score 0-100. >68 = good, >80 = excellent.
Đang dần được thay thế bởi UMUX-Lite.

### UMUX-Lite (2 câu)
Nhanh hơn SUS, độ chính xác tương đương:
1. "This system's capabilities meet my requirements"
2. "This system is easy to use"
(Likert scale: Strongly Disagree → Strongly Agree)

→ Phổ biến nhất trong product teams 2025-2026 (thay SUS 10 câu)

### NPS — Net Promoter Score
- "How likely are you to recommend this to a friend?" (0-10)
- Promoters (9-10) - Detractors (0-6) = NPS (-100 đến +100)
- > 0 = tốt, > 50 = excellent

## Product Metrics Framework

### North Star Framework (Amplitude)
Một metric duy nhất thể hiện core value:
- Spotify: Monthly active users + Engagement time
- Airbnb: Nights booked
- Slack: Daily active users

Ref: https://www.amplitude.com/north-star

### AARRR Pirate Metrics (Dave McClure)
- **Acquisition**: Cost per install, referral rate
- **Activation**: Signup completion, first-time experience
- **Retention**: Churn rate, day 1/7/30 retention
- **Revenue**: ARPU, LTV, conversion rate
- **Referral**: NPS, viral coefficient

## Cập nhật 2025-2026

### Product-Led Growth Metrics
- **Time to Value (TTV)**: Thời gian user trải nghiệm core value lần đầu
- **Feature adoption rate**: % user dùng specific feature
- **Expansion revenue**: Upgrade, cross-sell

### AI Product Metrics
- **AI Accuracy Score**: % responses correctly solving user intent
- **Fallback Rate**: Tỷ lệ AI fallback sang human/support
- **Trust Score**: User confidence in AI outputs (survey-based)

> ⚠️ **Cập nhật 10/2026:** HEART + North Star là bộ metrics phổ biến nhất trong tech companies 2025. UMUX-Lite thay thế SUS. AI product metrics đang được define mới.
