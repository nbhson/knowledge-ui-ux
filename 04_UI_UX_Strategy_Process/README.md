# 04. UI/UX Strategy & Process — Chiến lược và quy trình UX

## Quy trình thiết kế (Design Process)

### Double Diamond (British Design Council, 2005)
```
Discover → Define → Develop → Deliver
         (Problem)          (Solution)
```

1. **Discover**: Nghiên cứu, thu thập dữ liệu, tìm vấn đề
2. **Define**: Xác định rõ vấn đề cần giải quyết
3. **Develop**: Brainstorm, prototype, testing
4. **Deliver**: Hoàn thiện, triển khai

### Lean UX Process
```
Idea → Prototype → Test → Learn → (iterate)
```
- Giảm waste, tập trung vào validated learning
- Cross-functional team: UX + Dev + PM
- Working code > comprehensive documentation

### Design Sprint (Google Ventures, 5 ngày)
- Day 1: Map → HMW questions
- Day 2: Sketch solutions
- Day 3: Decide on the best
- Day 4: Prototype
- Day 5: Test with 5 users

## UX Strategy Framework

### Strategic Framework phổ biến
- **Value Proposition Canvas**: Problem-solution fit
- **Business Model Canvas**: Toàn cảnh business
- **OKRs cho UX**: Đặt objective + measurable results
- **Jobs-to-be-Done (JTBD)**: Người dùng "thuê" sản phẩm để làm gì

### UX Maturity Model (Nielsen Norman Group)
| Level | Mô tả |
|---|---|
| 1 | Absent — Không có UX |
| 2 | Ad-hoc — Occasional, không hệ thống |
| 3 | Emergent — Growing awareness, reactive |
| 4 | Systematic — Consistent process, design system |
| 5 | Sustainable — Strategic, UX metrics, C-level support |

## Deliverables phổ biến

- **User Personas**: Mô tả archetype user (needs, goals, pain points)
- **User Journey Map**: Hành trình user qua touchpoints
- **Service Blueprint**: Toàn cảnh service (frontstage + backstage)
- **Information Architecture (IA)**: Cấu trúc thông tin, navigation
- **Wireframe**: Sơ đồ layout không màu
- **Prototype**: Mô phỏng tương tác (low → high fidelity)
- **Design System**: Hệ thống component, token, guideline

## Cập nhật 2025-2026

### Continuous Discovery (Teresa Torres)
- Discovery Doorway: liên tục interview customers (không chỉ sprint)
- Opportunity Solution Tree (OST): từ outcome → opportunities → solutions
- Đây là cách tiếp cận phổ biến thay thế cho "big research upfront"

### AI trong Design Process
- Figma AI: layout suggestions, auto-layout improvements
- AI-generated personas từ research data
- Prototype generation từ wireframe description
