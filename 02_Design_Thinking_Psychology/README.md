# 02. Design Thinking & Psychology — Tư duy thiết kế & Tâm lý học

## Design Thinking Process (Stanford d.school, 5 bước)

```
Empathize → Define → Ideate → Prototype → Test
```

1. **Empathize**: Nghiên cứu người dùng, quan sát, phỏng vấn
2. **Define**: Tổng hợp insight → xác định vấn đề cần giải quyết (Point of View)
3. **Ideate**: Brainstorm giải pháp, không giới hạn ý tưởng
4. **Prototype**: Tạo prototype nhanh, low-fidelity
5. **Test**: Test với user, thu thập feedback → iterate

## Tâm lý học áp dụng trong UX

### Cognitive Psychology
- **Chunking**: Gom nhóm thông tin để dễ nhớ (7±2 items, Miller)
- **Dual Coding**: Kết hợp text + hình ảnh tăng khả năng tiếp thu
- **Cognitive Load Theory**: Giảm tải nhận thức — intrinsic, extraneous, germane load
- **Hick's Law**: Số lựa chọn tỷ lệ thuận với thời gian quyết định

### Behavioral Psychology
- **Fogg's Behavior Model**: B = MAT (Motivation, Ability, Trigger) → thiết kế để thúc đẩy action
- **Hook Model (Nir Eyal)**: Trigger → Action → Variable Reward → Investment → Trigger again
- **Operant Conditioning**: Phần thưởng biến thiên (variable reward) tạo thói quen
- **Loss Aversion**: Người ta sợ mất hơn thích được → dùng negative framing cho urgency

### Gestalt Principles trong Visual Design
- **Proximity**: Các object gần nhau được nhóm lại
- **Similarity**: Object cùng shape/color/size được nhóm
- **Closure**: Não người hoàn thiện hình dang từ fragments
- **Figure-Ground**: Phân biệt foreground/background rõ ràng
- **Continuity**: Não theo dõi đường liên tục

## Cập nhật 2025-2026

### Emotional Design (Don Norman, 3 levels)
Thiết kế hướng đến 3 mức độ cảm xúc:
- **Visceral**: Vẻ bề ngoài → ấn tượng đầu tiên (aesthetic)
- **Behavioral**: Trải nghiệm sử dụng → pleasure & effectiveness (usability)
- **Reflective**: Ý nghĩa, bản sắc, identity → self-image & satisfaction

### AI Design Co-pilot
- Design sprint với AI: dùng ChatGPT/Claude để generate personas, journey maps
- AI không thay thế empathizing nhưng tăng tốc synthesizing
